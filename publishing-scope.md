# Publishing scope, attribution và an toàn dữ liệu

## Được đưa vào portfolio

- Kiến trúc, vai trò, quyết định kỹ thuật và kết quả kiểm tra.
- Tên module, công nghệ và pipeline ở mức đủ để người tuyển dụng hiểu năng lực.
- Liên kết tới repo công khai do đúng owner/upstream cung cấp.

## Không tự động đưa lên GitHub

- .env, token, OAuth client, voice profile hoặc API key.
- Audio mẫu, dữ liệu huấn luyện, media generated và output lớn.
- EPUB/truyện, series bible, shotlist hoặc tài liệu thuộc quyền sử dụng riêng.
- Cache, log session, approval record và state vận hành.
- Toàn bộ repo upstream mà local workspace chỉ là clone/tham chiếu.
